## 实测（reference2.png，639×737）

```
球心      (0.509W, 0.513H)      几乎正中心
球径      0.40W
分界线    过 (1.014W, 0)，dx/dy = −0.826，即与水平夹角 50.4°
线宽      0.103W
球心到线心垂距 0.062W            → 线是穿球的，不是相切
```

色值全部取样，未调色：黄 `#EECD14`、蓝灰 `#708584`、线 `#F7F5E6`、球 `#16131B`。

## 两处修正

**1. 球径 0.40 → 0.34。** 0.40 是相对方形照片量的。放进圆形头像后同样的比例视觉过重，会把分界线吃掉大半、只剩两小段白线。0.34 保留「压线」关系，同时让线还能读出来。

**2. 线穿过球时，在球内收窄（10.3 → 2.8）。** 这一条同时解决三件事：

- 线不断（球盖住线的话，线会断成两截）
- 球是完整的圆（线压在球上的话，球会被劈成两半）
- 那条窄缝正好就是篮球的球缝

**没有第 2 条，单色版直接不成立。** 单色靠三档明度重排（左块实墨、右块中灰、球反白），白球压在墨线上、缝和线连成一体，线才仍然是连续的。

## 已知限制

- **篮球的语义靠语境。** 这个图形本身是「圆 + 线 + 双色块」，不像第一版那样一眼是篮球。在公众号里靠账号名和内容补足，单独拿出来（比如印在别处）识别度低于第一版。
- **32px 以下球缝消失**，球退回成实心圆。彩色版仍成立，单色版不要用。
- **单色版弱于第一版。** 第一版靠形状分层，缩到 16px 还认得出；第二版必须重排明度，且 24px 以下就糊。
- 黄 `#EECD14` 饱和度很高，在白色信息流里非常跳——这是优点也是风险，取决于你想要的调性。
