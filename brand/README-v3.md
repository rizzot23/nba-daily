# 去球吧 · 标志第三版（照片简笔画）

参考视觉还是 `reference2.png`（黄蓝双色地 + 球压分界线），但画法换了。

```
v1  篮筐 + 球 + 地板     →  照片位置体量落地，几何化
v2  双色地 + 球压线       →  几何抽象，球是一个实心圆，没有球缝
v3  同一张照片           →  照片简笔画，四色平涂，球是球
```

v2 的问题一句话说清：把照片压成两片色块 + 一条线 + 一个黑圆，信息量掉到只够当"抽象符号"。在订阅号列表里它读作"圆 + 斜线 + 色块"，读不出篮球。v3 把照片里每一条结构线都留下，只把质感换成平涂。

| | v2 | v3 |
|---|---|---|
| 画法 | 几何抽象 | 照片简笔画 |
| 球 | 实心圆，靠"线在球内收窄"假扮球缝 | 橙球 + 四条真球缝 |
| 线过球 | 收窄穿过，线不断 | 被球挡断（照片原样） |
| 球径 | 34（视觉修正） | 43（照片实测 46） |
| 目录 | `out2/` | `out3/` |
| 脚本 | `render_v2.py` | `render_v3.py` |

## 重新实测

v2 的测量把照片宽高都归一化到 100，等于把 639×737 压成正方形，纵向压掉 13%，所以球径、线角度都有偏差。v3 改用正确映射：**取照片中心正方形（y 49..688）铺满圆直径 100 单位，1 单位 = 6.39 px。**

```
球心      (309, 391) → (48.4, 53.5)，照片宽度的 48.4%
球半径    146 / 6.39 = 22.85  → 取 21.5（球占宽 46% → 43%）
白线      x = 653.5 − 0.7766 y，法向宽 55 → 8.5（与水平夹角 50.4°）
球缝宽    10 px → 1.6（放大到 1.9，标志化）
```

色值取样：黄 `#EECD13` · 蓝灰 `#718785` · 暖白 `#F5F4D6` · 球 `#D4844B` · 缝 `#24150D`。
蓝灰比 v2 的 `#708584` 略亮、球比实测 `#CE7E49` 略亮——都是为了让球在黄底上不显脏，幅度在 ±6/255 内。

## 球缝：这版的核心，也是踩坑最多的地方

照片里能看到四条缝：横缝、竖缝、左侧一条弧、右侧一条弧。**但这是斜俯视拍出来的，不能逐点照抄。**

按照片实测的坐标画出来的第一版是这样的：横缝被透视压在球心上方 0.46R，左右两条弧离球缘只剩 0.08R；四条缝的端点在球顶挤成一团，左右弧变成"第二圈轮廓"。结果像个地球仪，甚至比 v2 更不像球。

原因是照片里有三样东西简笔画没有：**缝在球缘转折处的自然消失、缝宽的两头收细、球面的明暗**。少了这三样，"贴边弧 + 密集线头"就只剩线条本身。

所以最终按简体画的方式提炼，规则三条：

1. **横缝留在球心上方 0.28R**（初版为了"不头重脚轻"压到了 0.10R，结果俯视感全丢，球像正对着看）。照片实测 0.46R，取 0.28R 是上限的一半：再高球顶那圈就挤，再低就退回侧面平视。
2. **左右弧离球缘 0.22R**。离得太近会变成描边，太远又挤中间。
3. **四条缝的端点在球缘处各自收口，互不汇聚**。这条是"像不像篮球"的胜负手——端点一旦在球顶拉在一起，立刻变成经纬网。

四条缝都用椭圆弧生成（球面上任何球缝的正交投影都是椭圆），整组再绕画心倾斜 **+6°**，对应照片里横缝左高右低、往右下走约 5° 的姿态。注意符号：画布 y 轴向下，顺照片方向是正角；写成负角会把横缝掰成右高左低，和照片相反（这是改版时踩过的坑）。

```python
mer   = _ell( 0.03, 0,    0.20, 1.10, -π/2, π/2)   # 经线，穿过球心，微右凸
eq    = _ell( 0,    -0.28, 1.06, -0.14, π, 2π)     # 纬线，球心上方 0.28R，中央下凹
left  = _ell(-0.42, 0,    0.36, 1.04, π/2, 1.5π)   # 左经线，离缘 0.22R
right = _ell( 0.42, 0,    0.36, 1.04, -π/2, π/2)   # 右经线
TILT  = +6°
```

`eq` 的两个数分工不同：`cy` 决定整条缝的高低（俯视感的强弱），`b` 决定中间往下凹多少（凹得越多，越像"近边"朝观者翻过来）。

```python
eq = _ell(0, -0.28, 1.06, -0.14, π, 2π)
#           ↑cy 定高低        ↑b 定下凹
```

## 字标组合：活泼的地方只留一处

`v3-lockup.png` 是"标志 + 去球吧 + NBA 每日战报"的横排组合，用在文章页眉和封面角落。

小字那行原本是 27px 纯黑、字距为 0，读起来像说明文字，整份组合就它最板。改了三件事：

1. **名字放大到 74px**，和小字拉开体量差（8:2.6）。原来 64 偏保守。
2. **名字下面一道手绘黄划**。这是整份组合里唯一的"手写"，也是唯一让静态字动起来的东西。做成两头收细、中间最粗、整条微翘 3° 的曲线——直接一根等宽直线会读成尺子画的，反而更死。代码是 `_swipe()`。
3. **小字加 1.4 字距**（PIL 没有 letter-spacing，`_tracked()` 逐字排）。

**为什么不给小字也加装饰**：试过把小字装进黄胶囊、给小字加下划线。胶囊让画面出现两块黄（左边那个大圆已经是一块黄），重复且抢名字；小字下划线在页眉缩到 330px 宽时直接消失，等于白做。**活泼只能有一个落点，落两个就变吵。**

页眉实景：`_header_mock` 仅供看效果，未入库；需要时按 330px 宽调用即可。

## 已知限制

- **48px 以下球缝会糊成一条黑线**，球退回成"橙圆带几道黑"。轮廓（黄/蓝斜切 + 中心橙球）仍然成立，这比 v2 好——v2 在 48px 只剩色块。
- **单色版必须给球描一圈反色边**。单色里球和线同为纸白，不描边两者会粘成一片，看着像国际"禁止"符号。`build(edge=...)` 就是干这个的。
- **没有画球下的投影**。照片里球左下有一块深色影，那是照片感的重要部分，但在圆形头像里会把左下角弄脏，且和左右弧打架。要更"照片"可以加，不建议。
- **球的橙色和底下黄色只隔 0.22 的明度差**，球压在黄地上的那半圈边界靠球缝和色相差撑住，没有描边。印在低质量纸上时注意。
