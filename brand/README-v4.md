# 去球吧 · 文字标志（v4）

不画球、不画线、不上图，只用**得意黑**排字。两件东西：

| 件 | 样子 | 用在哪 |
|---|---|---|
| 字标 | 去球吧 三字横排，墨色，透明底 | 封面、页眉插图、文末署名、名片 |
| 头像 | 黄圆 + 「球吧」两字，墨色 | 公众号 / 头条号头像 |

## 为什么头像只用两个字

公众号列表里头像约 48px。**圆内接正方形的边长只有直径的 0.707**，三字排进去每个字约 11px，48px 时就是一团墨；两字能到 17px，48px 清楚、32px 勉强可辨（实测放大截图见下）。

「球吧」不是硬截出来的缩写，它本身是个能读的词，和账号名同源。三字的版本也留在 `cand/` 里（`B_头像·三字.png`），想看可以对比。

## 字距：等距排不等于看起来等距

三个字等距排出来，去与球几乎粘住、球与吧却空一大块。原因是笔画形状不同：

- 「去」右侧是两道长斜笔，字面外拓 → 右边要多留
- 「球」左右都收，底部长撇外伸 → 左边要多留、右边可压紧
- 「吧」左边是方框，边缘硬 → 前面可以压

所以按字形给两个不同的间隙，跟数学等距无关：

```python
GAPS = (-0.004, -0.085)   # (去→球, 球→吧)，单位 em
```

四组对比过（等距 −0.053 / −0.012 & −0.075 / −0.004 & −0.085 / +0.004 & −0.092），第三组在视觉上最匀，第四组「球吧」开始相碰。

## 头像的安全边

`AV_INSET = 0.19`。这是字的外接框到圆边的距离，占直径的比例。0.13 时字顶到圆边发紧，0.22 又显小；0.19 是这三档里唯一两全的。

## 已知限制

- **32px 以下「球」字右半（求）会糊**，只剩「一个方块加一个字」的轮廓。48px 是这条路线的底线，公众号列表用的就是 48。
- **只有一档字重**。得意黑是单一字重字体，字标里做不出粗细对比；想让某个字更重，得自己描边（`stroke_width`），放大后会脏，不建议。
- **不能再加装饰**。文字标志的全部信息就是笔画和间距，加黄划、加方框都会让它变回图形标志。
